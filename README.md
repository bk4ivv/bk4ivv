## Featured Project

### FIM — Foreigner in Malaysia

[FIM](https://github.com/bk4ivv/fim-foreigner-in-malaysia ) is a Flutter Android application designed to help foreigners living and working in Malaysia find important information and services in one place.

The project focuses on:

- Malaysian government and support services
- Immigration and worker resources
- Transportation and travel information
- Malaysian culture and language learning
- Multilingual navigation and localized content
- Practical tools for everyday life in Malaysia
- Offline-friendly access to important information

## Technologies

- Flutter
- Dart
- Android
- Material Design
- WebView integration
- JSON-based content and country data
- GitHub Actions
